# Ait — инструкция для ИИ-агента

Этот файл для ИИ-агента (Claude Code, Codex, Cursor и т. п.), которого человек попросил установить и настроить
Ait на своём Mac. Выполняй шаги по порядку и проверяй результат каждого. Общайся с человеком на его языке.

**Что такое Ait.** Приложение голосового ввода для macOS, сделанное для русского и казахского: человек зажимает
правый ⌥, говорит, отпускает — текст вставляется в активное поле. Распознавание локальное (модели GigaAM-Multilingual).

**Что будет установлено** (всё в пространстве пользователя, `sudo` не нужен):

| Что | Где | Размер |
|---|---|---|
| приложение | `/Applications/Ait.app` | ~1 MB |
| движок: Python 3.12, onnx-asr, ONNX Runtime | `~/Library/Application Support/Ait/` | ~210 MB |
| модели: GigaAM обычная, пунктуация, VAD | `~/Library/Application Support/Ait/models/` | ~490 MB |
| журнал | `~/Library/Logs/Ait/engine.log` | — |

## Правила

- Не используй `sudo` и не меняй системные настройки безопасности: не отключай Gatekeeper и SIP, не трогай базу TCC.
- Разрешения «Микрофон» и «Универсальный доступ» может выдать только человек. Открой ему нужный раздел и объясни, что нажать.
- Перед снятием карантина с приложения (шаг 2) спроси человека: это отключает проверку Gatekeeper для Ait.
- Если шаг упал — покажи человеку вывод ошибки и строки из `~/Library/Logs/Ait/engine.log`, не придумывай обходные пути.

## Шаг 0. Проверить Mac

```bash
uname -m                                   # должно быть: arm64
sw_vers -productVersion                    # должно быть: 14.0 или новее
df -h ~ | tail -1                          # свободно хотя бы 2 GB
pgrep -x Ait && echo "Ait уже запущен"     # если запущен — это обновление, его закроем на шаге 1
```

Если `uname -m` не `arm64` или macOS старше 14 — остановись и скажи человеку, что Ait не поддерживает этот Mac.

## Шаг 1. Скачать и поставить приложение

```bash
TMP="$(mktemp -d)"
curl -fL -o "$TMP/Ait.zip" https://github.com/izzatillasapayev-eng/Ait/releases/latest/download/Ait.zip
pkill -x Ait 2>/dev/null; sleep 1
rm -rf /Applications/Ait.app
ditto -x -k "$TMP/Ait.zip" /Applications/
rm -rf "$TMP"
codesign --verify --strict /Applications/Ait.app && echo "подпись в порядке"
```

## Шаг 2. Карантин Gatekeeper

Ait подписан, но не нотаризован Apple. Файлы, скачанные через `curl`, обычно не получают карантин,
и тогда этот шаг не нужен. Проверь:

```bash
xattr -p com.apple.quarantine /Applications/Ait.app 2>/dev/null && echo "есть карантин" || echo "карантина нет"
```

Если карантин есть — спроси человека и, только получив согласие, сними его:

```bash
xattr -dr com.apple.quarantine /Applications/Ait.app
```

Если человек против — пусть сам откроет Ait и нажмёт «Всё равно открыть» в
Системных настройках → Конфиденциальность и безопасность.

## Шаг 3. Установить движок распознавания

Скачивает ~470 MB, обычно 1–3 минуты. Все файлы проверяются по SHA-256; повторный запуск докачивает только недостающее.

```bash
/Applications/Ait.app/Contents/MacOS/Ait --install-engine
```

Успех — последняя строка `OK: движок установлен в …` и код выхода 0. Ошибка — строка `ERROR: …`.

Модель **GigaAM Large** точнее, но тяжелее (+430 MB на диске, ~0.6 GB памяти во время диктовки вместо ~0.3 GB).
Ставь её, только если человек хочет максимальное качество:

```bash
/Applications/Ait.app/Contents/MacOS/Ait --install-engine --model large
```

## Шаг 4. Проверить распознавание

Синтезируй тестовую фразу голосом macOS и распознай её:

```bash
say -v Milena -o /tmp/ait-test-ru.wav --data-format=LEI16@16000 "Привет, это проверка голосового ввода"
/Applications/Ait.app/Contents/MacOS/Ait --selftest /tmp/ait-test-ru.wav
```

Ожидается строка вида `TEXT (1.2 s): привет это проверка голосового ввода`. Для казахского, если в системе есть голос `Aru`
(`say -v '?' | grep kk_KZ`):

```bash
say -v Aru -o /tmp/ait-test-kk.wav --data-format=LEI16@16000 "Сәлеметсіз бе, бүгін кешке жиналысқа келе аласыз ба"
/Applications/Ait.app/Contents/MacOS/Ait --selftest /tmp/ait-test-kk.wav
rm -f /tmp/ait-test-ru.wav /tmp/ait-test-kk.wav
```

Если голосов нет — пропусти, это не ошибка установки.

## Шаг 5. Настроить под человека

Спроси человека, что ему нужно, и запиши настройки **до запуска** Ait (если Ait запущен — `pkill -x Ait`):

| Ключ | Тип | Значения | По умолчанию | Что значит |
|---|---|---|---|---|
| `model` | string | `base`, `large` | `base` | `large` — только если поставлена на шаге 3 |
| `punctuation` | bool | `true`, `false` | `false` | точки, запятые и заглавные буквы (+0.13 GB памяти) |
| `startMode` | string | `cold`, `hot` | `cold` | `cold` — модель выгружается при простое; `hot` — всегда в памяти, без задержки |
| `unloadMinutes` | int | `0`, `1`, `5`, `15`, `60` | `5` | через сколько минут простоя выгружать модель (для `cold`) |
| `hotkey` | string | `rightOption`, `rightCommand`, `rightControl`, `rightShift` | `rightOption` | клавиша диктовки |
| `enabled` | bool | `true`, `false` | `true` | включена ли диктовка |

Пример:

```bash
defaults write com.izzatilla.ait punctuation -bool true
defaults write com.izzatilla.ait model -string large
defaults write com.izzatilla.ait startMode -string hot
```

Автозапуск при входе в систему включается только из меню самого Ait: «Запускать при входе в систему».

## Шаг 6. Запустить и выдать разрешения (делает человек)

```bash
open /Applications/Ait.app
```

Скажи человеку:

1. **Микрофон.** macOS спросит доступ — нажать «Разрешить».
2. **Универсальный доступ.** Нужен, чтобы Ait слышал горячую клавишу и вставлял текст. Открой ему раздел:
   ```bash
   open "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility"
   ```
   В списке включить **Ait** (если его нет — нажать «+» и выбрать `/Applications/Ait.app`).
3. Пока чего-то не хватает, значок Ait в строке меню показывает ⚠︎. Когда всё выдано — значок становится звуковой волной.

## Шаг 7. Финальная проверка с человеком

Попроси человека поставить курсор в любое текстовое поле (например, в Заметках), **зажать правый ⌥**, сказать фразу
по-русски или по-казахски и отпустить. Текст должен появиться в поле. Если не появился:

| Симптом | Причина и решение |
|---|---|
| ничего не происходит, значок ⚠︎ | нет Универсального доступа или микрофона — шаг 6 |
| ничего не происходит, значок — волна | выключить и снова включить Ait в Универсальном доступе, затем `pkill -x Ait; open /Applications/Ait.app` |
| плашка «Ошибка: …» | смотри `tail -50 ~/Library/Logs/Ait/engine.log`, при проблеме с движком — повтори шаг 3 |
| «Движок распознавания не установлен» | повтори шаг 3 |

Расскажи человеку, как пользоваться:
- **зажать правый ⌥** — запись, отпустить — вставка;
- **коротко нажать** — запись до следующего нажатия, **Esc** — отмена;
- все настройки — в меню значка Ait в строке меню.

## Обновление и удаление

Обновить: повтори шаги 1 и 3 (движок и модели сохраняются, докачивается только новое).

Удалить полностью (приложение, движок, модели, журнал, настройки и разрешения):

```bash
curl -fsSL https://raw.githubusercontent.com/izzatillasapayev-eng/Ait/main/scripts/uninstall.sh | bash
```
